# 家庭名称修改验收（2026-10-20）

## 范围与规则

- “家庭成员和计划”顶部仅当前家庭管理员显示“修改家庭名称”。服务端在同一事务锁内重新检查当前角色。
- 去除首尾空白，名称为1～64个Unicode字符，不接受控制字符。允许同名家庭，按家庭ID更新。
- 保存中禁用重复提交和家庭切换；取消不写入，失败保留草稿并显示原因。相同名称重复保存成功。
- 仅更新家庭名称和更新时间，不改变成员、邀请码、计划、完成记录及其他家庭。
- 首页分享标题同步为“爸妈动起来 - 带着家人一起动起来吧”。
- 接口：`PUT /api/family/:id/name`；仅接受`name`字段。无数据库结构变更。
