# 家庭计划首版实施与验收

范围：家庭内个人计划、共同计划、每天自动显示任务、管理员代建修改、简化完成操作。独立私有计划、复杂排期和报表后置。只修改和本地验证，不部署、不上传、不提交审核。

实现约定：个人计划仅指定执行者产生任务；管理员和本人可管理。共同计划成员自行加入，创建者可只负责安排。既有目标按共同计划保留，既有参与及历史不重写。动作修改保存新版本，今天已有进度时次日生效，否则当天生效；历史完成记录始终指向原动作要求。后台统计复用同一完成明细，避免新造一套计数。

成员范围：产品重点服务爸妈锻炼，但“爸妈”不是系统角色或身份限制。配偶、子女及其他亲友均可作为家庭成员加入；权限以管理员和普通成员区分，管理员可为任意成员安排个人计划。功能使用“家庭成员”等通用称呼，不新增亲属身份或年龄限制。

| 影响 | 验收 |
| --- | --- |
| 创建及权限 | 管理员代建不自动参与；普通成员只能建本人个人计划；共同计划不得强制加入他人；跨家庭拒绝 |
| 修改及历史 | 管理员转移后权限即时更新；动作修改前后历史组数/次数不变；当天已开始次日生效；旧页面不得提交过期动作 |
| 参与生命周期 | 共同计划加入重试幂等；退出后不能提交；家庭移除和重新加入保留既有历史；个人计划不能由别人加入 |
| 今日任务 | 本人个人计划和已参与共同计划自动显示；旁观管理员不算欠任务；空数据和失败分别呈现 |
| 完成及统计 | 一键完成、部分完成、重复请求、跨日请求；按人/日/计划动作计数，个人/家庭/后台明细可对账 |
| UI | 管理操作收起，无原因表单；小屏、滚动、底部安全区、进度及编辑错误可恢复 |
| 回归范围 | 全部 Node 页面测试、全部 Go 测试、独立 MySQL 集成测试、Go build、管理后台 build、官方模拟器回归；真机未执行不得标记通过 |

## 已实现的首版行为

- 管理员选择一位家庭成员创建个人计划；该成员立即成为执行者，无确认步骤，管理员不会因此自动参与。
- 普通成员可以创建自己的个人计划。个人计划可由执行者或当前家庭管理员修改；本期不支持更换执行者或计划类型。
- 共同计划可由创建者和当前管理员维护，家人自主加入、退出；创建者可以只负责安排。
- 首页“今天做什么”只显示本人参与的有效计划；真正无任务、加载中和加载失败分别呈现。切换账号或退出登录后忽略旧请求结果。
- 详情提供动作示范、完成全部、可选的分组记录。编辑、暂停、恢复、退出放在“更多”，不要求填写原因。
- 计划动作保留不可变版本。当日已有进度时，动作要求次日生效；未开始时当天生效。历史详情使用该日期的动作快照，禁止提交历史进度或过期动作。
- “次数”沿用同一人、同一天、同一计划动作全部完成计一次；组数独立累计。重复请求不重复计数。周图展示实际完成组数，历史日期没有完整计划快照时不显示达标率。
- 家庭移除成员后，当前参与人数不再包含该成员，历史记录保留并标记离开。再次加入恢复原关联，历史不复制。
