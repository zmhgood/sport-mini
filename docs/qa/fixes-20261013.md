# 2026-10-13 小程序修复记录

本批次仅修改小程序代码与本地测试。未部署服务器、未上传替换体验版、未提交小程序审核。

## 用户可见变化

- 家庭成员开始锻炼前，若尚未参与目标，先确认加入目标，再记录进度。取消或加入失败不进入提交页。
- 进度加载失败时提供重试；提交期间及成功后防止重复提交。错误提示保留服务端原因。
- 家庭邀请使用微信原生分享入口，收件人打开含邀请码的加入页，登录后仍须明确确认加入。
- 推荐、分类列表和动作详情分别展示加载、失败、空数据；删除失败后的假动作数据，避免旧分类请求覆盖新分类。
- 动作图片保留完整画面；底部三个 Tab 图标放大并居中，标签单行，底部安全区独立留白。
- 分类列表仅在成功取得结果后显示动作数量，避免加载/失败时误显示“共 0 个动作”。
- 个人页页脚读取 `wx.getAccountInfoSync().miniProgram.version`。平台没有返回数字版本时显示开发版、体验版或正式版，不沿用旧版本号。
- 字体大小、语音播报、锻炼提醒、紧急联系目前未实现，统一标为“暂未开放”；原有家庭、目标、个人信息入口保留。
- 仅微信开发工具的开发环境使用本地 API；手机预览、体验版、正式版使用线上 API。

## Decisions 使用方式

优先用程序断言检查可读状态和数据，再用 Decisions 检查固定视觉条件，未知或低置信度结果转交进一步分析。2026-10-13 同模型、同一四检查点流程各跑三轮：普通 Responses 视觉判断中位 15.52 秒，Decisions 10.32 秒，程序断言 1.87 秒。Decisions 比普通视觉流程减少 33.5%，两者均 12/12 正确。这是样本流程结果，不代表整个产品或 Codex 交互测试的总提速；未知状态回退本轮未触发。
