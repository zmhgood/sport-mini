# 家庭页和目标详情加载态修复 — 2026-10-12

状态：代码修复与本地验证完成；本次仅提交 Git，未部署、上传或提交审核。

家庭页原先根据初始空数组显示“您还未加入家庭”，目标详情根据尚未返回的数据显示 0 人/0 动作。两页现在先显示“正在加载”，所有依赖成功后才显示内容；失败显示可重试提示，成功空数据仍按原有内容展示。刷新时隐藏旧数据；进行中的重复加载不再次请求。

家庭加载依次获取列表，再并行获取所选家庭详情和目标；目标详情并行获取目标与进度。数据获取方法返回结果，由页面统一更新，避免失败尝试的迟到响应覆盖新结果。两页统一从 onShow 加载，首次进入不重复请求。家庭切换及移除/转移后的刷新使用同一加载入口。
